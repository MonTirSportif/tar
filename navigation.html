Naviguer dans le site

Plusieurs façons de découvrir le site TAR, le Tir aux Armes Réglementaires. Les rubriques sont les mêmes, seule la manière de les parcourir change : choisissez celle qui vous convient.

1
Accès direct par thèmeVous savez ce que vous cherchez : tous les thèmes sont visibles d’un coup d’œil.
2
Parcours selon votre profilVous découvrez le TAR, vous le pratiquez ou vous encadrez : suivez les rubriques dans l’ordre qui vous correspond.
3
Selon votre écranTéléphone, tablette, ordinateur ou papier : les astuces pour chacun.

Variante 3

Selon votre écran

Le site s’adapte à l’appareil que vous utilisez. Votre écran actuel est signalé.

Votre écran

Téléphone

  • Le sommaire de l’accueil montre les 3 premières rubriques : touchez « Voir plus » pour tout afficher.
  • Le menu du haut défile du doigt.
  • Le bouton ↑ remonte en haut de la page.
Votre écran

Tablette

  • Les tuiles s’affichent sur deux colonnes, faciles à toucher.
  • Le fil d’Ariane, en haut de chaque page, ramène à l’accueil.
Votre écran

Ordinateur

  • Toutes les rubriques sont accessibles depuis le menu du haut et le sommaire.
  • Ctrl + F (ou ⌘ + F) cherche un mot dans la page.
  • Dans les questions fréquentes, le champ de recherche filtre les réponses.
Votre écran

Papier

  • Le bouton Imprimer de cette page donne la liste de toutes les rubriques.
  • Chaque page s’imprime proprement, sans menus.
